## Daily routine
- Read the current progress log.
- Implement one focused, reviewable milestone.
- Run relevant checks.
- Update progress and methodology.
- Make a separate commit for the increment.
- Report results and blockers.

## Completion criteria
Dataset terms, reproducible loading, EDA, explicit causal estimand/assumptions, baseline and DML inference if valid, robustness checks, transparent pricing scenarios, notebook, report, and presentation outline.

**Integrity rule:** If the data does not support a defensible causal effect, make that finding explicit. Never invent metrics or claim guaranteed profit improvements.
